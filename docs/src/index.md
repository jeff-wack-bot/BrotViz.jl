# BrotViz.jl

Plotting for [Mandelbrot.jl](https://github.com/jeffwack/Mandelbrot.jl):
Hubbard trees, external rays, spiders, Mandelbrot and Julia sets, and wedge
diagrams for binary expansions and kneading sequences, on any Makie backend.

## Development notes

[Mandelbrot and BrotViz development notes](@ref) is a transcription of the
handwritten notes from August 2, 2026. The prose is reproduced as written;
each hand-drawn figure is replaced by one generated with BrotViz, and the
code that draws it sits directly above it.
